# Codex 科研工作流

用 Codex 组织科研项目、分配聊天任务，并让每个任务把结果保存到明确的位置。

## 快速开始

1. 把 [`initial.md`](initial.md) 放入你的科研项目根目录。
2. 在科研项目根目录创建 `相关资料/`，放入论文、参考代码、数据说明等资料，可以保留子目录。
3. 在项目的第一个聊天中发送：**“请根据 initial.md 中的内容创建任务聊天。”**
4. 助手会准备项目文件，并创建或列出 6 个任务聊天。
5. 研究阶段、核心结论或下一步变化时，让“01 研究路线”聊天更新项目 README。

如果当前版本不能自动创建多个聊天，按 `initial.md` 中列出的名称和第一条消息手动创建即可。

## 资料索引

“02 资料理解”首次启动会阅读 `相关资料/` 中的资料，并生成项目根目录的 `资料索引.md`。每份资料记录编号、摘要、路径、关键位置和关联资料，其他 Agent 据此快速找到原文。

以后加入或替换资料，在“02 资料理解”中发送：**“请更新资料索引。”** 它会检查目录变更，更新索引和相关笔记。该任务未运行时，索引不会自行刷新。

## 六个任务聊天

1. **01 研究路线**：维护研究问题、假设、计划和项目进度。
2. **02 资料理解**：整理论文、数据集和代码中的可核对事实。
3. **03 实现与复现**：修改代码并完成小规模验证。
4. **04 实验分析**：比较实验结果，排查异常并整理图表。
5. **05 文章写作**：组织大纲、正文、图表和引用。
6. **06 独立审查**：检查公式、实现、实验和结论。
