## 项目结构

- `AGENTS.md`：助手需要遵守的项目规则。
- `research-plan.md`：研究问题、假设、基线和实验计划。
- `status.md`：最近一次任务的交接信息。
- `相关资料/`：放入论文、参考代码、数据说明等输入资料，可按主题建子目录。
- `资料索引.md`：由“02 资料理解”生成，按编号、摘要及路径定位资料；所有 Agent 共用。
- `notes/`：论文、数据集和代码阅读笔记。
- `experiments/`：配置、日志、图表和分析。
- `draft/`：文章草稿。
- `reviews/`：审查记录。

新增或替换资料后，在“02 资料理解”聊天中发送：**“请更新资料索引。”** 它会阅读变化内容并更新索引。该任务未运行时，索引不会自行刷新。
